# Leafy Pond

A small, quiet, touch-friendly pond game. Move the floating leaves and watch their delicate trails fade into the water.

## Run locally

Open `index.html` in a modern browser. For the install/offline features, serve the folder over localhost or HTTPS.

## Publish with GitHub Pages

The repository includes a GitHub Actions workflow that deploys the site when you push to `main` (or `master`). In the repository, open **Settings → Pages** and make sure the build and deployment source is set to **GitHub Actions**. The first deployment will then run automatically.

## Controls

- Drag a leaf with a mouse, finger, or stylus.
- Tap the music-note button to turn on a soft ambient water-like sound.

No score, timer, or objective — just a pond to play with.
